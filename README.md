# GymTrack

A full-stack workout tracking application designed to help users organize their training and track their fitness journey.

# Features

 **User Authentication**
    Register and log in to a personal account.
 **Workout Management**
    Create, edit, save, and manage workouts.
 **Workout History**
    Keep track of completed workouts.
 **Progress Tracking**
    Monitor workout streaks and personal bests.
 **Personal Dashboard**
    View workout information and progress in one place.
 **Profile Management**
    Manage personal account information and profile picture.
 **Personalized Experience**
    Each user has their own workouts and training data.

# Technology & Purpose

| Technology | Purpose |

| React | Frontend user interface |
| JavaScript | Application logic |
| Node.js | Backend runtime |
| Express.js | Backend API |
| PostgreSQL | Database |
| REST API | Frontend/backend communication |
| CSS | Styling and responsive layouts |
